INSTALL

Start with a clean device.

Use a desktop Chrome or Edge browser and a USB data cable. Select the ESP32’s CH340 serial port, not the RP2040 port.

Fresh installation replaces ESP32 settings, identities, keys and message history.Back up anything you want to retain first. The SD card is not formatted.

This browser does not support Web Serial. Open this page in desktop Chrome or Edge.

Open this installer over HTTPS or on localhost.

Confirm the hardware and fresh-install notice to enable installation.

ON YOUR DEVICE

Make it yours.

  1. Set up Meshtastic.Choose your region and configure your node and channels.
  2. Open Modes.Switch to MeshCore. Both firmwares keep separate settings in internal flash; switching does not require SD backups.
  3. Set up MeshCore radio.Transmission starts disabled. Enter your frequency, bandwidth, spreading factor and scope under Radio, then save. This preview supports 902–928 MHz.
  4. Add HamView and time.Enter your own Wi-Fi and HamAlert credentials. Tap the clock for UTC/local time and time-zone options.

RP2040 COMPANION / SD CARD

Need the storage bridge update?

The browser installer programs the ESP32 only. SD support requires the RP2040 companion firmware with protocol v2; v2.1 is provided below. Use the documented BOOTSEL procedure and copy the UF2 file to the RP2040 drive.

Never use an ESP32 image on the RP2040, or a UF2 file in the ESP32 installer.

Download official RP2040 v2.1 ↓RP2040 installation guide ↗

No prefilled owner data

No saved owner names, node keys, contacts, Wi-Fi credentials, HamAlert logins or coordinates are included. Keys and identities are created on your device.

Two full firmwares

One protocol runs at a time. Modes selects the other firmware and restarts. Your two profiles have independent internal filesystems.

Preview release

Core functionality has been checked on a SenseCAP. The clean factory-install path has been verified offline, not flashed onto a second blank device. This is an independent implementation; complete CAIRN parity is not claimed.

Command-line installation and update notes

Install esptool, download the factory image, close other serial applications and run:

python -m pip install esptool
python -m esptool --chip esp32s3 --port YOUR_PORT --baud 460800 write-flash 0x0 sensecap-dual-0.1.0-preview.factory.bin

This is a fresh install, not a settings-preserving update. Ordinary OTA updates are disabled to protect the other firmware slot. See the repository for the layout, build source, limitations and recovery information.
